# Melia's iPhone — Closet to the Bone (Prototype v3)

A fictional iPhone-inspired interface with a Liquid Glass-inspired visual treatment and an interactive Messages thread.

## What's new in v3
- Ezra and Melia's conversation now begins with ordinary, familiar exchanges so the reader experiences their friendship before the incident.
- Melia tells Ezra about finding her blood-stained underwear in a public changing locker at UCL. She is venting and asking for help; she does not suspect him.
- Reader choices shape how Melia explains the incident and what she asks Ezra to help with. The conversation then advances to the unsuccessful checks and Ezra's offer of his Belgravia home.
- The Belgravia invitation is presented as a later message, after the incident and their attempts to understand it.
- Existing Settings, Find My, Notes and investigation notebook screens remain available.

## Files
- `index.html` — page structure
- `style.css` — phone frame and interface styling
- `app.js` — navigation, message history, dialogue choices and clue notebook

## Run
Open `index.html` in a modern browser. No build tools or dependencies are required.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `app.js`, and `README.md` to the repository root.
3. Go to Settings → Pages.
4. Choose Deploy from a branch, select `main` and `/ (root)`, then save.

This is a fictional simulation. It does not access real messages, location, or device data. Dialogue is prototype content and can be revised to match the final chapter chronology.
