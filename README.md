# Melia's iPhone — iPhone 17 / iOS 26 simulation (v4)

This is a standalone browser prototype. It has no build step or external dependencies.

## Included
- iPhone 17-style hardware proportions and rounded display
- Dynamic Island and status bar
- Lock Screen with notification preview
- Six-digit passcode keypad; correct passcode: `280108`
- iOS-style Home Screen, widget, app grid and dock
- Functional prototype screens for Messages, Settings, Find My, Notes, Photos, Calendar, Safari and other app icons
- Messages conversation where Melia vents to Ezra; she does not suspect him
- Branching response choices and a clue notebook

## Run locally
Unzip the folder and open `index.html` in a modern browser. For GitHub Pages, upload all four files to the repository root.

## Important
This is a visual and narrative simulation, not an actual iPhone operating system. Face ID, camera, microphone, live location, real notifications and real messages are not accessed. The passcode is a fictional story gate, not real device security.
